# Stoboy — интернет-магазин авторского мерча

Учебный проект интернет-магазина авторского мерча с авторскими иллюстрациями, аксессуарами и канцелярией.

## О проекте

Stoboy — веб-интерфейс интернет-магазина, ориентированный на удобный просмотр каталога и взаимодействие с товарами. Визуальная концепция разработана с учётом целевой аудитории и особенностей авторского бренда.

## Основные разделы

- Главная страница с информацией о магазине
- Каталог товаров
- Корзина
- Вход и регистрация
- Личный кабинет

## Технологии

- HTML5
- CSS3 / SCSS
- JavaScript
- Figma — проектирование интерфейса

## Что было сделано

- Разработка макета интерфейса
